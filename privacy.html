Política de privacidad de Jarvis

Última actualización: 7 de noviembre de 2026

Jarvis es un sistema personal de organización de uso privado: lo usa una sola persona, Martín García, con su propia cuenta de Google. No es un servicio público y no admite registros de otros usuarios.

Qué datos de Google usa

Jarvis solo accede a los eventos de Google Calendar de la cuenta del propio Martín García.

Para qué los usa

  • Leer los eventos para preparar su resumen diario de agenda.
  • Crear en su calendario los eventos que él mismo dicta o escribe.

Dónde se guardan

Los eventos siguen en Google Calendar. Los datos que Jarvis necesita para funcionar se guardan en una base de datos propia en Supabase, alojada en la Unión Europea.

Procesamiento del texto

El texto de los mensajes que Martín envía a Jarvis se procesa con la API de Anthropic para entender qué pide.

Con quién se comparten

Los datos no se comparten con terceros, no se venden y no se usan para publicidad.

Cumplimiento

El uso y la transferencia de la información recibida de las API de Google cumplen la Google API Services User Data Policy, incluidos los requisitos de uso limitado (Limited Use).

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com → Seguridad → Apps de terceros con acceso a la cuenta.
